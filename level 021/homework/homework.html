Java-ს ისტორია

Java შეიქმნა 1995 წელს James Gosling-ის მიერ Sun Microsystems-ში. თავდაპირველად ის განკუთვნილი იყო ინტერნეტ აპლიკაციებისთვის, მაგრამ მალე გახდა ერთ-ერთი ყველაზე პოპულარული პროგრამირების ენა.

Java-ს მახასიათებლები

  • პლატფორმის დამოუკიდებლობა: "Write Once, Run Anywhere" (WORA)
  • ობიექტზე ორიენტირებული პროგრამირება
  • დიდი სტანდარტული ბიბლიოთეკა
  • მძლავრი უსაფრთხოების მექანიზმები

დამატებითი რესურსები

თუ გსურთ მეტი გაიგოთ Java-ს შესახებ, შეგიძლიათ ეწვიოთ ოფიციალურ ვებგვერდს: Oracle Java
